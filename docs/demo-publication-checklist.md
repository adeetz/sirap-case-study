# Private Demo Access Policy

The live walkthrough is shared privately on request. Before providing access,
confirm every item below.

## Isolation

- [ ] The public demo uses an isolated database containing only fictitious fixtures.
- [ ] The public demo uses isolated storage for all uploaded evidence and media.
- [ ] No data, files, accounts, or session stores are shared with non-public environments.

## Access model

- [ ] A Viewer account can explore read-only reporting views.
- [ ] A Staff account can create and edit only its own fictitious reports.
- [ ] A Verifier account can demonstrate the review flow only for fixtures.
- [ ] No Super Admin or finance-administration access is publicly available.

## Reset and monitoring

- [ ] A documented reset process restores fixtures and removes visitor-created changes.
- [ ] The reset process is tested before publication and has an owner.
- [ ] Upload limits, file validation, and private evidence access are verified in the isolated environment.

## Portfolio review

- [ ] Every screenshot uses fictitious or redacted data.
- [ ] No production credentials, infrastructure details, or private files appear in repository content.
- [ ] No public demo URL or test credential is published in repository content.
- [ ] The private walkthrough environment is checked before access is shared.
